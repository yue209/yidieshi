# 一叠事

一个面向实习生任务协作的静态 Web 工作台，把需求接收、路线图、排期协商、今日推进、等待跟进和周报证据整理成六个独立功能。

当前版本依据《实习生任务管理台 PRD》与卡片切换参考图实现，保留 PRD 中的真实字段、业务规则、空状态、加载/错误、数据保存、导入导出和减少动态效果设置。

## 功能

- 需求接单台：保留原始需求、结构化字段、追问清单和 AI 兜底。
- 实习项目路线图：按阶段展示目标、成果物、截止时间和任务步骤。
- 工作负荷协商台：平铺日期卡、任务时间块、冲突提示和协商建议。
- 今日推进台：最多三张重点任务卡堆，支持点击、按钮和拖动切换。
- 等待跟进台：纵向跟进卡、下一次跟进时间和话术草稿。
- 周报证据台：来源卡、证据列表、文稿面板和导出。

## 本地预览

这个项目是纯静态站点，入口文件在 `dist/index.html`。

```bash
npx serve dist
```

也可以直接用浏览器打开 `dist/index.html`。

## 部署到 Vercel

仓库根目录包含 `vercel.json`，Vercel 会把 `dist` 作为静态输出目录。

推荐设置：

- Framework Preset: Other
- Build Command: 留空
- Output Directory: `dist`
